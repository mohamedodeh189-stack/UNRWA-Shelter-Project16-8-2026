# ملخّص الميزات — Features Summary
## مشروع المأوى في الأونروا (إصدار ميداني 19.1)

قائمة مختصرة بالميزات المنجزة وقيمتها الميدانية.

---

## الميزات المنجزة

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **العمل دون إنترنت (Offline-first)** | كل البيانات والصور محلية على الجهاز. | العمل لا يتوقف داخل المخيم حيث لا تغطية. |
| **إنشاء دراسة سريع** | حفظ الاسم والبيانات الأولية بلا قائمة مسبقة. | البدء فوراً من الميدان. |
| **ملف مستفيد موحّد** | مسار عمل واضح + حالة اكتمال الملف. | يعرف المهندس ما أنجز وما ينقص بلمحة. |
| **فريق الدراسة والتاريخ** | تسجيل المهندس/الباحث وتاريخ الدراسة. | توثيق المسؤولية عن كل ملف. |
| **حفظ العنوان الأصلي** | العنوان الأصلي لا يُعدَّل ولا يُحذف + تحديد القطاع. | مرجعية ثابتة لا تُفقد عند التعديل. |
| **جدول كميات مرجعي (37 بنداً)** | إدخال الكمية → حساب السعر والإجمالي والدفعتين 60٪/40٪. | تسعير موحّد ودقيق بلا حسابات يدوية. |
| **تصدير الكميات Excel** | ملف Excel مستقل بالكميات. | مشاركة/مراجعة الكميات خارج التطبيق. |
| **رسم مخطط المنزل** | معايرة + جدران/غرف/أبواب/نوافذ + أبعاد داخلية + شمال. | مخطط ميداني دقيق دون أدوات خارجية. |
| **تصدير المخطط DXF/PDF** | DXF هندسي (1 وحدة = 1 متر) + PDF للعرض. | ملف قابل للقياس والتعديل في AutoCAD، وليس صورة. |
| **الحزمة بزر واحد** | مجلد تسليم من 7 مجلدات: كميات، CAD، صور، بيانات. | ملف نهائي منظّم وجاهز للأرشفة والمراجعة. |
| **فتح مجلد المستفيد** | فتح مجلد التسليم من داخل التطبيق. | وصول مباشر للملفات النهائية. |
| **دورة الاعتماد والمراجعة المكتبية** | draft → إرسال → مراجعة → اعتماد نهائي. | مسار اعتماد واضح، والقرار النهائي بشري. |
| **الخريطة التشغيلية** | قطاعات المخيم + فلاتر (قائمة/قطاع/حالة/موقع) + بطاقة نقطة. | رؤية ميدانية لتوزيع المستفيدين والتخطيط للزيارات. |
| **GPS تقديري وحقيقي** | يبدأ تقديرياً (مركز القطاع) ثم يُثبَّت حقيقياً عند الزيارة. | تمييز واضح بين موقع مُقدَّر وموقع مؤكَّد. |
| **صور «قبل الترميم» المرجعية** | استيراد صور مرجعية للقراءة فقط + «التقاط بنفس الزاوية». | مقارنة قبل/بعد من نفس الزاوية، دون المساس بالأصل. |
| **مراحل تصوير التنفيذ** | صور «قبل / أثناء / بعد الترميم» منفصلة. | توثيق مراحل العمل بصرياً. |
| **النسخ الاحتياطي/الاستعادة (JSON)** | تصدير/استيراد الدراسات والكميات وفهرس الصور. | حماية البيانات ونقلها بين الأجهزة. |
| **الحماية بـ PIN** | قفل التطبيق بكود اختياري. | حماية البيانات الشخصية على الجهاز. |
| **مجلد حفظ قابل للتغيير** | اختيار المجلد الرئيسي لملفات المشروع (SAF). | تحكّم المستخدم بمكان الحفظ. |
| **دليل استخدام داخلي** | شرح تفاعلي + دليل PDF. | تسهيل التبنّي دون تدريب مطوّل. |
| **واجهة عربية بأرقام لاتينية** | تصميم ميداني موحّد. | وضوح وسرعة في الاستخدام الميداني. |

## صفحة المتابعة كأداة تسليم ميداني (FOLLOWUP V2 · F1–F6) ⭐ جديد

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **F1 — استيراد ZIP واحد** | ملف مضغوط يحوي كل شيء؛ يكتشف ملف العناوين تلقائياً كمصدر رسمي، ومن لا عنوان له يأخذ عنوان التقييم ويُوسَم «من التقييم». | استيراد بسيط وموثوق، عناوين أدق بلا تخمين. |
| **F2 — فصل ملف المتابعة عن الدراسة** | يُخفي أدوات الدراسة/الرسم؛ شارة مصدر العنوان؛ فصل الصور المرجعية عن «الوثائق المستوردة». | ملف متابعة نظيف ومركّز على التنفيذ. |
| **F3 — حالة التسليم والعدّادات** | ٦ حالات + «تسليم الأعمال» بتأكيد وتاريخ و«سجل التسليم» + عدّادات و٩ فلاتر. | يعرف المهندس من سلّم وكم بقي أثناء الجولة. |
| **F4 — الأعمال المطلوبة + الأولوية + الدفعة** | كل بند BOQ بحالته، اقتراح أولوية التنفيذ، واقتراح ما ينفَّذ ضمن الدفعة الأولى — بأسعار BOQ فقط. | تنظيم التنفيذ وترشيد الدفعة (اقتراح مساعد لا قرار). |
| **F5 — تحليل العناوين** | شجرة القطاع ← الشارع ← الجادة مع العدّادات وفتح قائمة كل عنوان. | تخطيط ميداني سريع للتوزيع الجغرافي. |
| **F6 — مزامنة جهات الاتصال باسم مختصر** | «الاسم ق<القائمة> مستفيد» + التفاصيل في الملاحظات. | اتصال سريع وأسماء واضحة بلا إطالة. |

> الاقتراحات (الأولوية/الدفعة) **مساعدة للمهندس وليست قرارات**، والأسعار من ملف الكميات المستورد فقط، ولا اعتماد أو صرف تلقائي.

**تحسينات:** إصلاح عرض رقم التسجيل («00162351‑1» بدل المقلوب) — عرض فقط دون تغيير البيانات.

## وضع الرسم الميداني السريع (Drawing Fast Field Mode) ⭐ جديد

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **وضع الرسم الميداني السريع** | مفتاح واحد يضبط: إدخال سنتيمتر + طلب طول الجدار بعد الرسم + الأبعاد الداخلية الصافية. | المهندس يبدأ الرسم السريع فوراً بلا إعداد. |
| **وحدة الإدخال متر/سنتيمتر** | 500 تعني 5.00 م، مع بقاء التخزين الهندسي بالمتر. | إدخال ميداني طبيعي دون خلط. |
| **غرفة بالأبعاد + نوع الغرفة** | اختيار النوع ثم الطول×العرض → غرفة كاملة مسمّاة فوراً. | غرفة خلال ثوانٍ بدل رسم أربعة جدران. |
| **إدخال طول الجدار بعد الرسم** | نافذة سريعة اختيارية تثبّت الطول الحقيقي بعد الرسم. | دقّة دون إبطاء تسلسل الرسم. |
| **البعد الداخلي الصافي** | الأرقام هي القياس الداخلي كما يُقاس ميدانياً. | تطابق الرسم مع القياس الفعلي على الأرض. |
| **Extend Wall (تمديد الجدار)** | يمدّ طرف الجدار الحر حتى أقرب جدار دون قطعة صغيرة. | وصل الجدران بسرعة ونظافة. |
| **أدوات الباب والشباك السريعة** | عكس اتجاه الفتح (Mirror/يمين‑يسار/داخلي‑خارجي) وتغيير العرض دون حذف. | تعديل سريع بدل الحذف وإعادة الرسم. |
| **شرح المعايرة الأوضح** | يوضّح معنى المعايرة ويعرض «1 م = N px» بعد الضبط. | فهم أسرع للمقياس دون التباس. |

> **حفاظ على الدقة الهندسية:** التخزين الداخلي يبقى بالمتر، ويبقى **1 وحدة CAD = 1 متر** في تصدير DXF.

## سهولة القراءة الميدانية ⭐ جديد

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **حجم الخط (عادي/كبير/كبير جداً)** | خيار في الإعدادات يكبّر النصوص الأساسية في كل التطبيق، محفوظ في SharedPreferences فقط. | قراءة أسهل ميدانياً دون كسر الواجهة. |
| **تحسين تباين المظهر الداكن** | ألوان النص «theme-aware» — لا نص غامق فوق خلفية غامقة؛ العناوين والنصوص واضحة في الوضع الداكن، والبطاقات الداكنة بنص أبيض. | وضوح تام في الوضعين الفاتح والداكن. |

> الوضع الفاتح لم يتغيّر؛ التحسين خاص بالقراءة والتباين فقط دون المساس بالهوية البصرية.

## مجلد المشروع — مجلد رئيسي واحد لكل الحفظ ⭐ جديد

**يعتمد التطبيق على مجلد مشروع رئيسي واحد يتم اختياره مرة واحدة، وتُحفظ داخله كل ملفات المستفيدين تلقائياً.**

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **مجلد مشروع واحد** | يُختار مرة واحدة قبل أول دراسة؛ كل الصور والكميات وCAD/PDF وbackup والحزمة تُحفظ داخله تلقائياً في مجلد المستفيد الصحيح. | لا أسئلة متكررة عن مكان الحفظ — قرار واحد فقط. |
| **الصور تُحفظ حيّاً في مكانها** | كل صورة تذهب مباشرة إلى `03/04/05` داخل مجلد المستفيد دون منتقي مجلد. | تصوير سريع دون انقطاع. |
| **تغيير المجلد / فقدان الإذن** | تنبيه واضح عند التغيير (لا نقل تلقائي للقديم)، وإعادة طلب الاختيار إذا فُقد الإذن أو حُذف المجلد. | لا فشل صامت ولا ملفات ضائعة. |

> يُحفظ التفضيل في SharedPreferences فقط (لا تغيير في قاعدة البيانات، ولا reset/clear).

## تحسينات الاستخدام الميداني — الحاسبة والخريطة والصور ⭐ جديد

| الميزة | ماذا تفعل | قيمتها الميدانية |
|---|---|---|
| **حاسبة كميات احترافية** | لوحة أزرار كبيرة تدعم `3.2+4.5+2.1` و`(3×4)+(2×1.5)` + استبدال/إضافة. | حساب عدة أضلاع/مساحات لبند واحد بسهولة. |
| **التكلفة والإجمالي مباشرةً** | تكلفة كل بند والإجمالي والدفعتان تتحدّث فور الإدخال. | معرفة المبلغ فوراً دون حفظ. |
| **أماكن الضرر بالبطاقات** | لكل بند: المكان + نوع الضرر + كميته بالبطاقات، مع مجموع واعتماد ككمية البند. | فريق المتابعة يعرف أين ينفّذ دون الرجوع لمهندس الدراسة، وبلا كتابة طويلة. |
| **إخفاء «الوثائق المستوردة»** | لا تظهر كبطاقة في المتابعة (الملفات محفوظة). | صفحة متابعة أنظف. |
| **صور «قبل الترميم» المرجعية** | شبكة ٣/صف أسفل «قبل الترميم» + «نفس الزاوية» + تصدير إلى `مرجعية_مستوردة` بلا تكرار. | مرجع واضح لإعادة التصوير. |
| **دليل الخريطة (؟)** | شرح مختصر ميداني للخريطة. | استخدام أسرع بلا حيرة. |
| **إصلاح تداخل القطاعات** | بطاقة القطاع تفتح مستفيدي **نفس القطاع فقط**؛ عند التداخل «اختر القطاع». | لا خلط بين العروبة والتقدم وشرق اليرموك. |
| **تحليل العناوين داخل الخريطة** | شجرة القطاع ← الشارع ← الجادة/الحارة، مقيّدة بالقطاع. | تخطيط جولات دقيق من مكان واحد. |
